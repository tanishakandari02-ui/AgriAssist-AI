# 🌾 AgriAssist AI

## Project Overview

AgriAssist AI is a smart agriculture web application that helps farmers with crop information, weather updates, government schemes, market prices, secure authentication, and AI-powered crop disease detection.

---

## Features

- User Registration
- User Login
- Google OAuth Login
- Crop Information
- Weather Updates
- Government Schemes
- Market Prices
- AI Crop Disease Detection
- Responsive Design

---

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL (Prisma)

### Authentication
- JWT

- Google Gemini API
