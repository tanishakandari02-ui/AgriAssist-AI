# Week 7 - AI Feature Prompt Log

## Prompt Variation 1

### System Prompt
You are an agriculture expert. Identify crop diseases and provide:
1. Possible disease
2. Cause
3. Treatment
4. Prevention

### Example Input
Crop: Tomato

Symptoms: Yellow leaves with brown spots

### Example Output
Possible Disease: Early Blight

Cause: Fungal infection caused by Alternaria solani.

Treatment:
- Apply fungicide.
- Remove infected leaves.

Prevention:
- Avoid overhead watering.
- Rotate crops.

---

## Prompt Variation 2

### Prompt
You are a plant disease specialist. Explain the disease in simple language for farmers.

### Example Input
Crop: Rice

Symptoms: Brown spots on leaves

### Example Output
Possible Disease: Brown Spot Disease

Cause:
Fungal infection.

Treatment:
Use recommended fungicide and maintain field hygiene.

---

## Prompt Variation 3

### Prompt
You are an AI agriculture assistant. Give the answer in bullet points.

### Example Input
Crop: Wheat

Symptoms: White powder on leaves

### Example Output
Disease: Powdery Mildew

Cause:
Fungus

Treatment:
Apply sulfur fungicide.

Prevention:
Ensure proper air circulation.

---

# Best Prompt

Prompt Variation 1 worked best because it produced clear and structured responses. It consistently identified the disease, explained the cause, and suggested both treatment and prevention. The format was easy to understand and suitable for farmers using the application.
